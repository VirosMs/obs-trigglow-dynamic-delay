🚀 Trigglow Dynamic Delay para OBS — v0.3.0 ya disponible: menos RAM, misma calidad

Ya sabes lo que hace: activa o desactiva un delay en tu stream directamente desde OBS, sin apps
externas ni paneles aparte, sin que el stream se corte ni se reconecte jamás.

Qué trae v0.3.0:
• Compresión real del buffer en RAM (MJPEG) en Windows y Linux — misma calidad mínima que elijas,
  sin bajarla nunca, solo menos RAM ocupada
• Medido en una sesión real de 30s a 1080p60: el uso de RAM del buffer bajó de ~6.3GB a ~2.9GB
• Fallback automático y seguro a lo de siempre si el codec no está disponible — la compresión nunca
  es un requisito para que el buffer funcione
• macOS sigue funcionando exactamente igual que antes (sin comprimir) mientras no exista un build de
  FFmpeg de confianza para esa plataforma

Sigue siendo Early Access: estable para probarlo con tu equipo, con un roadmap claro de lo que viene
después.

Descárgalo y lee cómo funciona: https://www.trigglow.com/dynamic-delay
